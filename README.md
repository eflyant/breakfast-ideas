# Сніданок? Легко!

Українська добірка 10 сніданків: mobile-first, фільтри, улюблені в localStorage, випадковий рецепт, список інгредієнтів і посилання на благодійний збір.

## Локально

Потрібні Node.js 24 та Python 3. Зовнішніх залежностей немає.

- `npm run dev` — локальний сервер на порту 3000.
- `npm run build` — статичні файли у `dist/`.
- `npm start` — сервер для зібраної версії.

## Vercel

Імпортуйте репозиторій. `vercel.json` задає команду збірки й каталог `dist`. Домен та секрети не потрібні.

## Контент

Рецепти в `recipes.json`. Кількості на 2 дорослих та 1 дитину, невеликі порції. Час орієнтовний. Фотографії всіх 10 рецептів зберігаються в `assets/`. Для чіа-пудингу й вівсянки враховується ніч у холодильнику; фільтр «До 10 хв» показує час активної підготовки.

Улюблені зберігаються лише в браузері на цьому пристрої. Галочки інгредієнтів зберігаються протягом відкритого сеансу сторінки.
